Protocol:

- preprocessing: `raw` và `log1p_scale`;
- `StandardScaler.fit` chỉ trên train;
- K = 2..8;
- seeds = 0..9;
- `n_init=20`, `max_iter=300`;
- stability = pairwise ARI trên train assignment;
- metric: train/validation inertia + silhouette + cluster size + stability;
- baseline A: mô tả không clustering;
- baseline B: raw K=2 seed 42;
- **không đọc test**;
- **không auto-select K**.

Trạng thái: code đã commit nhưng chưa có log local cho harness mới, nên chưa ghi experiment PASS và chưa có kết quả K nào.
